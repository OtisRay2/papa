# Otis Presentation

A presentation built with [Slidev](https://sli.dev/) using the Amexio theme.

## Development

Install dependencies:

```bash
npm install
```

Start the dev server:

```bash
npm run dev
```

Visit http://localhost:3030 to view the presentation.

## Build

Build the presentation for production:

```bash
npm run build
```

Export to PDF:

```bash
npm run export
```

## Deployment

This presentation is automatically deployed to GitHub Pages via GitHub Actions whenever changes are pushed to the main branch.

**Live URL:** https://otisray2.github.io/papa/

## Theme

This presentation uses the [Amexio Slidev Theme](https://github.com/amexiogroup/amexio-slidev).
